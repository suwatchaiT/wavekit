# Security Policy

## Supported version

WaveKit Beta 0.1 is the currently supported version. Security fixes are applied to the latest code on the default branch.

## Reporting a vulnerability

Do not publish a security vulnerability in a public issue.

Use GitHub’s private vulnerability-reporting feature when it is enabled for this repository. If private reporting is unavailable, contact the repository owner through their GitHub profile and request a private reporting channel.

Include the affected route or component, reproduction steps, potential impact and any suggested mitigation. Do not include real customer, network or credential data.

You should receive an acknowledgement within seven days. Public disclosure should wait until a fix or mitigation is available.

## Scope

Relevant reports include cross-site scripting, unintended information exposure, unsafe URL-state handling, dependency vulnerabilities and deployment-configuration weaknesses.

Incorrect engineering formulas should be reported through the normal issue tracker unless they create a security impact.
